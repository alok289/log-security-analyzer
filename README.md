# Log Analysis & Security Threat Detection System

A Python-based log analysis tool that analyzes login activity and detects suspicious authentication attempts.

## Features

- Analyzes login logs
- Detects failed login attempts
- Detects successful login attempts
- Extracts IP addresses from logs
- Identifies suspicious IP addresses
- Detects multiple failed login attempts from the same IP
- Generates a security report

## Technologies Used

- Python
- Regular Expressions
- File Handling
- Log Analysis

## Requirements

- Python 3.x
- No external libraries required

## How to Run

python log_security_analyzer.py

Example output
Security Analysis
-----------------
Failed login attempts: 5
Successful logins: 3

Suspicious IP Addresses:
192.168.1.50 - 3 failed attempts

Security report saved as: security_report.txt

Purpose

This project was developed to understand basic security log analysis, authentication monitoring, IP address analysis, and suspicious activity detection using Python.
